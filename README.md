
## Installation

`cp .env.example .env`

make the needed changes regarding name, url, database connection

`php artisan migrate`

`php artisan excel:sync`

`php artisan excel:watch`

`composer install`

`php artisan db:seed`

`npm install`

`php artisan serve` and `npm run dev`

`php artisan queue:work`

`php artisan make:filament-user`
